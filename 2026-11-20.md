## Releases

- **Haveno v1.13.0** ([release](https://github.com/haveno-dex/haveno/releases/tag/v1.13.0), 14 Nov): a security-heavy release. It updates Tor to 0.4.9.15, asks for the wallet password before showing private keys, offers only a plain file name when saving dispute attachments, prevents forged mailbox messages from hiding real ones, rate-limits permanent data from peers and keeps the Monero node login out of the wallet process command line. UI changes include an interactive market depth chart and optional signed payment accounts for takers of XMR-selling offers.
- No new tags for monero or monero-gui (still v0.18.5.4), the FCMP++/Carrot stressnet (still v0.19.0.0-beta.3.1) or Cuprate (still cuprated 0.1.0-preview).

## monero (core): 38 PRs merged

Four merge batches (13, 16, 18 and 19 Nov) brought FCMP++ follow-ups, n-of-n multisig fast setup and a lot more wallet hardening.

- **FCMP++:** UkoeHB's follow-up review of the tree-building DB integration ([#11741](https://github.com/monero-project/monero/pull/11741), reviewing [#11425](https://github.com/monero-project/monero/pull/11425)); a stronger DB check when overwriting the last layer element in the tree ([#11734](https://github.com/monero-project/monero/pull/11734)); removal of leftover DB-migration artifacts ([#11738](https://github.com/monero-project/monero/pull/11738)); a tx-pool cache of invalid input verification IDs, which j-berman describes as an interim fix until a future sync protocol stops storing alt-block txs in the pool ([#11737](https://github.com/monero-project/monero/pull/11737)); test improvements ([#11717](https://github.com/monero-project/monero/pull/11717)); and a MinGW link-order fix for the Rust FCMP++ library ([#11746](https://github.com/monero-project/monero/pull/11746)).
- **Multisig:** the CLI wallet can now do an N-of-N "fast" non-interactive multisig setup that skips the post-KEX round ([#11697](https://github.com/monero-project/monero/pull/11697), resolves [#8757](https://github.com/monero-project/monero/issues/8757)).
- **Tx proofs:** "refuse InProofs for transactions the wallet sent" ([#11655](https://github.com/monero-project/monero/pull/11655)), pulled from the merge queue last week pending agreement on the breaking change, was merged on 16 Nov after it came up at the tech meeting. Also: v1 spend proofs are bound to the requested transaction ([#11696](https://github.com/monero-project/monero/pull/11696)), `check_tx_key` verifies the v1 txid ([#11693](https://github.com/monero-project/monero/pull/11693)) and unverifiable message signatures are rejected ([#11675](https://github.com/monero-project/monero/pull/11675)).
- **wallet2 / wallet API:** keep inputs marked spent by a confirmed tx when a pending tx fails ([#11603](https://github.com/monero-project/monero/pull/11603)); lower the scan skip height on reorg ([#11732](https://github.com/monero-project/monero/pull/11732)); handle `.keys` saves and overlapping paths ([#11726](https://github.com/monero-project/monero/pull/11726)); check the upper bound in `fast_refresh` ([#11720](https://github.com/monero-project/monero/pull/11720)); expose double-spend status for incoming pool payments in the wallet API ([#11679](https://github.com/monero-project/monero/pull/11679)); keep multisig info, tx keys and command arguments out of simplewallet logs ([#11686](https://github.com/monero-project/monero/pull/11686), [#11691](https://github.com/monero-project/monero/pull/11691)).
- **Wallet RPC:** harden wallet filename validation ([#11724](https://github.com/monero-project/monero/pull/11724)); batch unspent counts in `get_balance` ([#11714](https://github.com/monero-project/monero/pull/11714)).
- **Networking:** schedule timed sync independently per network zone ([#11678](https://github.com/monero-project/monero/pull/11678)); ask for the next chain entry when the last one is already known, which stops repeated drop/reconnect loops ([#11653](https://github.com/monero-project/monero/pull/11653)); restore both anchor connections after a restart ([#11652](https://github.com/monero-project/monero/pull/11652)); resolve `--tx-proxy` hostnames ([#11529](https://github.com/monero-project/monero/pull/11529)).
- **Core / epee / RPC:** avoid a coinbase-sum deadlock ([#11710](https://github.com/monero-project/monero/pull/11710)); reject unsupported nested arrays in epee ([#11687](https://github.com/monero-project/monero/pull/11687)); refuse to overwrite existing update download destinations ([#11684](https://github.com/monero-project/monero/pull/11684)); linenoise/epee follow-up hardening ([#11619](https://github.com/monero-project/monero/pull/11619)).
- **Fuzzing:** four OSS-Fuzz target sets from arthurscchan: wallet proofs, FCMP++, wallet scan and wallet cache ([#11492](https://github.com/monero-project/monero/pull/11492), [#11453](https://github.com/monero-project/monero/pull/11453), [#11439](https://github.com/monero-project/monero/pull/11439), [#11438](https://github.com/monero-project/monero/pull/11438)).
